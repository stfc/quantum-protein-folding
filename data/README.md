# Data Directory Overview

## `raw` data

### `pdb`

This directory contains the data files for proteins, stored in the [Protein Data Bank format](https://www.rcsb.org).

## `processed` data

### `exact` bitstring energies

This directoy contains the distribution of all bitstrings corresponding to allowed bitstrings (as defined by unit Hamming weight in the rotomer qubit subspace), and their energies. These are generated by `scripts/calculate_exact_energies.py`.

### Pyrosetta data

This directory contains two subdirectories related to rotamer energy data generated using pyrosetta.

#### `pyrosetta_energy_files`
This directory stores rotamer energy files generated by the script `scripts/create_energy_files.py`.

#### `pyrosetta_energy_files_immutable`
This directory contains the rotamer energy files that were used in the simulations presented in the paper. These files are fixed and are not modified by the code. All optimisation results of the accompanying publication are based on the data stored in this directory.

### QAOA Data

This directory contains:

1. **Individual trajectory data**  
   - `mps-qaoa.csv` and `sv-qaoa.csv` contain data for individual trajectories produced by running `scripts/run_qaoa.py`.

2. **Paper Data**  
   - `mps-qaoa-paper.csv` and `sv-qaoa-paper.csv` include data used in the paper.  
   - These were generated by running multiple QAOA trajectories with different `initial_point` parameters and averaging the results. PLease see the paper for more details.
